# **02.asm**

The program demonstrates how a function sets up a stack frame to manage local variables using 64-bit registers.

1. Program executes 'call work', which automatically pushes the return address onto the stack, subtracting 8 from rsp.
2. Inside work, 'push rbp' saves the caller's old base pointer to the stack, subtracting another 8 from rsp.
3. 'mov rbp', rsp copies the stack pointer to rbp to anchor the new stack frame.
4. 'sub rsp', 16 subtracts 16 from rsp to allocate space on the stack for local variables.
5. The program writes 100 to [rbp - 8] and 200 to [rbp - 16], storing them directly in the stack space.
6. It then reads 100 from [rbp - 8] into rax and 200 from [rbp - 16] into rbx.
7. 'mov rsp, rbp' resets rsp back to rbp, clearing the allocated local variable space.
8. 'pop rbp' pops the old base pointer back into rbp and adds 8 to rsp.
9. ret pops the saved return address off the stack, adding 8 to rsp, and jumps execution back to _start.
10. The program sets up the exit syscall (rax=60) and executes syscall


## Observation
rbp serves as a stable base point for referencing local variables while rsp moves. The function sets up the stack frame at the start and cleans it up at the end, returning rsp to its starting state.
