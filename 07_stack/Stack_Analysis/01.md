# **01.asm**

The program demonstrates basic LIFO stack operations using 64-bit registers.

1. Program loads 100 into rax and 200 into rbx. The rsp (stack pointer) points to the initial top of the stack.
2. 'push rax' subtracts 8 from the stack pointer, then 100 is placed there. 
3. 'push rbx' subtracts 8 from stack pointer, and stores the value of rbx (200) at the new rsp address.
4. 'pop rcx' reads the 8 bytes at the current rsp and stores them in rcx and adds 8 to point to the next address at rsp
5. 'pop rdx' reads the next 8 bytes at rsp and stores them in rdx and adds 8 to rsp; and now rsp is back to its initial state.
6. The program sets up the exit syscall (rax=60)


## Observation
This illustrates the LIFO nature of the stack. rax was pushed first and rbx second, meaning rbx's value (200) was popped first into rcx, and rax's value (100) was popped second into rdx.
