# **05.asm**

The program demonstrates saving and restoring 64-bit hexadecimal register values using the stack.

1. Program loads '0x1122334455667788' into rax and 0x1234 into rbx.
2. 'push rax' subtracts 8 from rsp and places 0x1122334455667788 onto the stack.
3. 'push rbx' subtracts 8 from rsp and places 0x1234 on top of the stack.
4. 'pop rbx' reads the top 8 bytes at rsp (0x1234), places them back into rbx, and adds 8 to rsp.
5. 'pop rax' reads the next 8 bytes at rsp (0x1122334455667788), places them back into rax, and adds 8 to rsp.
6. The program sets up the exit syscall (rax=60) and executes syscall.


## Observation
Popping values in the exact reverse order of pushing them restores the registers back to their original states; a key technique for preserving data across code blocks.
