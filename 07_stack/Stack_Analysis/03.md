# **03.asm**

The program demonstrates implicit stack manipulation through call and ret control flow operations.

1. Program loads 10 into rax.
2. 'call calculate' automatically pushes the address of the next instruction (after_call) onto the stack, subtracting 8 from rsp, and jumps to calculate.
3. Inside calculate, 'add rax, 5' adds 5 to rax (making it 15) without altering the stack.
4. ret pops the saved return address from the top of the stack into the instruction pointer (rip), adding 8 to rsp, and returns to after_call.
5. The program sets up the exit syscall (rax=60) and executes syscall.


## Observation
Even without explicit push or pop instructions in the code, call and ret rely on the stack to keep track of execution flow and safely return to the calling code
