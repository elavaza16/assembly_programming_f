# **06.asm**

The program demonstrates saving and restoring 32-bit hexadecimal register values using the stack.

1. Program loads '0x11223344' into eax and 0x1234 into ebx.
2. 'push eax' subtracts 4 from esp and stores 0x11223344 on the stack.
3. 'push ebx' subtracts 4 from esp and stores 0x1234 on top of the stack.
4. 'pop ebx' reads the top 4 bytes at esp (0x1234), restores it into ebx, and adds 4 to esp.
5. 'pop eax' reads the next 4 bytes at esp (0x11223344), restores it into eax, and adds 4 to esp.
6. The program sets up the 32-bit exit syscall (eax=1) and triggers int 0x80.


## Observation
This works identically to 05.asm, but operates on 32-bit registers. Every push and pop modifies the stack pointer (esp) in 4-byte increments instead of 8.
