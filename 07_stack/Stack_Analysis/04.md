# **04.asm**

The program demonstrates stack frames and local variables in a 32-bit environment.

1. Program executes 'call work', which automatically pushes the 32-bit return address onto the stack, subtracting 4 from esp.
2. Inside work, 'push ebp' saves the caller's base pointer, subtracting 4 from esp.
3. 'mov ebp, esp' sets ebp as the base frame anchor.
4. 'sub esp, 8' subtracts 8 from esp to allocate 8 bytes for two 32-bit local variables.
5. The program writes 100 to [ebp - 4] and 200 to [ebp - 8] on the stack.
6. It then moves the value at [ebp - 4] into eax and [ebp - 8] into ebx.
7. 'mov esp, ebp' resets esp back to ebp, deallocating the local space.
8. 'pop ebp' pops the old base pointer back into ebp and adds 4 to esp.
9. ret pops the 32-bit return address into eip, adding 4 to esp, and jumps back.
10. The program sets up the 32-bit exit syscall (eax=1) and executes int 0x80.


## Observation
This follows the same stack frame logic as 02.asm, but operates in 32-bit mode. All stack operations adjust esp by 4 bytes instead of 8 bytes.
